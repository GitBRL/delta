Segurança

O Delta foi construído para que um erro no código não exponha dados de outra agência.

Isolamento no banco de dados

Toda tabela com dados de agência tem Row Level Security no PostgreSQL. A aplicação conecta com um usuário que não consegue ignorar essas regras: se uma consulta esquecer um filtro, o banco devolve só os dados da agência certa. Um teste automático impede que uma tabela nova entre sem essa proteção.

Credenciais e tokens

  • Tokens de acesso às plataformas e chaves dos apps ficam criptografados.
  • Tokens de API, de convites e de links públicos são guardados só como hash.
  • Webhooks de saída são assinados e não chegam a endereços internos.

Acesso das pessoas

  • Verificação em duas etapas e passkeys.
  • Papéis por agência (dono, administrador, analista e cliente) e portal do cliente só com os projetos dele.
  • Registro de auditoria de quem fez o quê.

WhatsApp e e-mail com consentimento

Envios só para contatos com consentimento registrado, e descadastro em um clique.
